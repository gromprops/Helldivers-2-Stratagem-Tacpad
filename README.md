# Helldivers 2 Stratagem Tacpad

Welcome to the Stratagem Tacpad README!  
This interactive cosplay prop is inspired by the *Helldivers* games. It simulates the in-game process of calling in support Stratagems with arrow-key commands. This guide will walk you through operation and troubleshooting.

## Safety & Care Instructions
- Keep the Tacpad dry and away from extreme heat.  
- Avoid dropping the device, as it may damage internal electronics.  
- Do not charge the device for more than 24 hours at a time, as this can degrade battery life.

## Power and Charging
The Tacpad includes a built-in battery and micro-USB charging port. Charge it fully before first use.  
- The charging indicator LED turns on when USB power is detected.  
- Use the power switch on the rear to turn the Tacpad on.

## Features & Operation

### Primary Operation
The touchscreen interface provides arrow keys for entering Stratagem sequences. When the entered sequence matches an equipped Stratagem, the Tacpad will signal activation.

1. Press the **silver Stratagem button** to activate the on-screen arrows.  
2. Tap the arrows in the correct sequence.  
3. When a sequence matches, the Stratagem will highlight on screen and the button LED will flash.  
4. Press the Stratagem button again to deactivate.  

![Tacpad Main Operation Mode](https://i.imgur.com/ergSwCE.jpeg)

---

### Stratagem Loadout Selection
You can store up to **4 equipped Stratagems** at startup. Optionally, you can enable randomization to get a new loadout every time the device boots.

- Press **LOADOUT** to open the menu.  
- Select desired Stratagems. Once four are chosen, the **CONFIRM** button activates.  
- **EXIT** discards changes and returns to main screen.  
- Random Loadout mode can be enabled in the configuration menu.  

![Tacpad Loadout Mode](https://imgur.com/iuoc0lX.jpeg)

---

### Settings Mode
Access settings by pressing the **gear button** in the menu bar. The current firmware version is displayed at the top of the menu.

- **Volume**: Adjust with +/- buttons.  
- **Stratagem Randomization**: Toggle random loadouts on/off.  
- **Stratagem Ball**: Enable wireless companion device.  
  - **Pair Button**: Starts pairing mode.  
  - **Ch**: Displays paired channel ID.  
- **Random Player**: Toggle on for random Player Tag and Super Destroyer name at boot.  
  - If toggled off, you can select custom values.  

---

### Software Updates
Updates are free and easy to install.  
1. Check your current firmware version in the Settings menu.  
2. Download the latest `.uf2` file from the [Releases page](https://github.com/gromprops/Helldivers-2-Stratagem-Tacpad/releases).  
3. Connect Tacpad via USB.  
4. Hold the **reset button** (next to USB port) while powering on.  
5. A USB storage device (`RP2350`) will appear.  
6. Drag the `.uf2` file into it. The Tacpad will reboot automatically with the update.

## USB Controller Configuration

The Tacpad can function as a **USB controller** for *Helldivers 2* on PC.  
This mode allows you to input Stratagem sequences directly in-game using the Tacpad’s buttons.

### Requirements
- A USB connection between the Tacpad and your PC.  
- Correct key bindings configured in the game settings.  

### Game Key Bindings
To use this feature, configure your in-game controls as follows:
- **Stratagem Up** → Up Arrow  
- **Stratagem Left** → Left Arrow  
- **Stratagem Down** → Down Arrow  
- **Stratagem Right** → Right Arrow  
- **Open Stratagem List** → **CTRL**  

### Using USB Controller Mode
1. Connect the Tacpad to your PC via USB.  
2. Hold the **Stratagem Button** to activate input mode.  
3. Use the Tacpad arrow buttons to enter Stratagem sequences.  
4. Release the Stratagem Button to complete the input.  

> **Note:** This feature requires the correct key bindings as listed above. If the keys are mapped differently in-game, the Tacpad will not function as intended.



## Wireless Module Installation
A wireless module is required to use the Stratagem Ball companion device.

1. Power down the Tacpad.  
2. Unscrew the four screws on the back casing.  
3. Locate the wireless module slot and 4-pin connector:  

![Wireless Module Connector](https://imgur.com/1WwZ17L.jpeg)

4. Position the module with the antenna facing **up**. The left edge slides into a notch in the housing.  

![Installed Wireless Module](https://imgur.com/IZ1NCFa.jpeg)

5. Plug the module cable into the socket.  
6. Reinstall the back casing.  
7. Ensure firmware is at least **v1.2**.  
8. Enable **Stratagem Ball** setting and pair with your Stratagem Ball.
